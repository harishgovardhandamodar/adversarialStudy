# Attack Taxonomy Report: Model Extraction on GNNs

## Overview

This report provides a detailed taxonomy of model extraction attacks (MEAs) against Graph Neural Networks. Each attack scenario is characterized by three adversary knowledge factors that fundamentally determine attack feasibility.

## The Three Knowledge Dimensions

### 1. Node Attribute Knowledge

| Level | Definition | Implementation |
|-------|------------|----------------|
| **Known** | Full feature matrix available | Clone target features exactly |
| **Partial** | Estimated features (neighborhood-level) | Average of attack node neighbors |
| **Unknown** | No features available | Replace with random Gaussian noise |

### 2. Graph Structure Knowledge

| Level | Definition | Implementation |
|-------|------------|----------------|
| **Known** | Full adjacency matrix | Direct use of target graph topology |
| **Partial** | Incomplete edges | Random edge dropout (50% retention) |
| **Unknown** | No structural knowledge | Empty graph (no edges) |

### 3. Shadow Dataset Availability

| Level | Definition | Impact |
|-------|------------|--------|
| **Known** | Auxiliary labeled data | Enables 50-epoch surrogate pre-training |
| **Unknown** | No auxiliary data | Forces 100-epoch direct extraction |

### Shadow Dataset Details

Shadow datasets are auxiliary graphs created with the same statistical properties as the target:
- **Generation**: Synthetic data generator with same seed distribution
- **Size**: 30% of target graph nodes
- **Fraud rate**: 1% (matching target)
- **Labels**: Generated by querying target model on shadow nodes (pseudo-labeling)

## Attack Scenarios (7 Total)

### Attack 0 — Low/Medium Knowledge (Partial Attribute + Partial Structure)

**Adversary knows**: Some features and edge structure
**Adversary lacks**: Full features, full topology
**Knowledge vector**: `[partial_attr, partial_struct, no_shadow]`

**Attack method**:
1. Sample ~25% of nodes for querying
2. Use local neighborhood to estimate missing features
3. Apply 50% random edge dropout to approximate topology

**Expected fidelity**: 0.45–0.60
**Difficulty**: Moderate — partial knowledge provides signal but limits precision

---

### Attack 1 — Low Knowledge (Partial Attribute + Unknown Structure)

**Adversary knows**: Some features
**Adversary lacks**: Any topological information
**Knowledge vector**: `[partial_attr, no_struct, no_shadow]`

**Attack method**:
1. Query target on randomly selected nodes
2. Use only node features (no edges) in surrogate
3. Train 100 epochs with limited signal

**Expected fidelity**: 0.40–0.55
**Difficulty**: Highest — most constrained attack

---

### Attack 2 — Medium Knowledge (Unknown Attribute + Known Structure)

**Adversary knows**: Full graph topology
**Adversary lacks**: Node feature values
**Knowledge vector**: `[no_attr, known_struct, no_shadow]`

**Attack method**:
1. Clone target adjacency matrix exactly
2. Replace node features with 3-d Gaussian noise
3. Train surrogate with full topology signal

**Expected fidelity**: 0.55–0.70
**Difficulty**: Moderate — structure compensates for lack of features

---

### Attack 3 — Medium Knowledge (Unknown Attribute + Unknown Structure + Known Shadow)

**Adversary knows**: Shadow dataset
**Adversary lacks**: Features, topology
**Knowledge vector**: `[no_attr, no_struct, has_shadow]`

**Attack method**:
1. Use shadow dataset to pre-train surrogate (50 epochs)
2. Shadow labels from target model guide surrogate
3. No structural or attribute knowledge needed

**Expected fidelity**: 0.50–0.70
**Difficulty**: Moderate — shadow data provides critical learning signal

---

### Attack 4 — High Knowledge (Partial Attribute + Partial Structure + Known Shadow)

**Adversary knows**: Features, partial edges, shadow data
**Adversary lacks**: Full topology
**Knowledge vector**: `[partial_attr, partial_struct, has_shadow]`

**Attack method**:
1. Pre-train surrogate on shadow (50 epochs)
2. Query additional nodes for fine-tuning (100 epochs)
3. Use noisy features + incomplete edges

**Expected fidelity**: 0.70–0.85
**Difficulty**: High — shadow data + partial knowledge is very powerful

---

### Attack 5 — Medium Knowledge (Partial Attribute + Unknown Structure + Known Shadow)

**Adversary knows**: Features, shadow dataset
**Adversary lacks**: Topology
**Knowledge vector**: `[partial_attr, no_struct, has_shadow]`

**Attack method**:
1. Pre-train surrogate on shadow data (50 epochs)
2. Fine-tune on extracted labels without structure (100 epochs)
3. Partial features + shadow provides strong signal

**Expected fidelity**: 0.60–0.75
**Difficulty**: Moderate — shadow compensates for missing structure

---

### Attack 6 — High Knowledge (Unknown Attribute + Known Structure + Known Shadow)

**Adversary knows**: Topology, shadow dataset
**Adversary lacks**: Node features
**Knowledge vector**: `[no_attr, known_struct, has_shadow]`

**Attack method**:
1. Pre-train surrogate on shadow with correct topology (50 epochs)
2. Fine-tune on extracted labels (100 epochs)
3. No features needed due to strong structural + shadow signal

**Expected fidelity**: 0.75–0.90
**Difficulty**: Easiest — most attack-effective scenario

## Threat Assessment by Adversary Profile

## Key Takeaways

1. **Structure matters more than attributes** — known topology consistently yields higher fidelity
2. **Shadow data is a force multiplier** — even without features, shadow + structure = high fidelity
3. **Unknown topology is the best defense** — attacks without structural knowledge struggle
4. **Partial knowledge is dangerous** — any additional knowledge layer significantly improves attack success
5. **Adversary knowledge is never truly "zero"** — in practice, attackers often obtain partial information
